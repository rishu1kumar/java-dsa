# Variables & Data Types Questions

## Question 1

Input 3 numbers — A, B, and C. Output the average of these 3 numbers.

**Hint:** Average of N numbers = sum of those numbers ÷ N

## Question 2

Input the side of a square. Output the area of the square.

**Hint:** Area of a square = side × side

## Question 3

Enter the cost of 3 items from the user (using the `float` data type) — a pencil, a pen, and an eraser. Output the total cost of the items back to the user as their bill.

**Bonus:** Try adding 18% GST to the bill as an advanced version of this problem.

## Question 4

What will be the data type of `result` in the following code?

```java
byte b = 4;
char c = 'a';
short s = 512;
int i = 1000;
float f = 3.14f;
double d = 99.9954;

result = (f * b) + (i % c) - (d * s);
```

**Hint:** Look at the largest data type involved in the expression.

## Question 5 (Advanced)

Will the following statement throw an error in Java?

```java
int $ = 24;
```
